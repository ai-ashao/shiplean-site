# ShipLean Site

[简体中文](README.zh-CN.md)

Public bilingual marketing website for ShipLean, an Agent-ready TanStack Start SaaS scaffold.

This repository contains the website only. The commercial scaffold and its bundled Skill belong in a separate private repository.

## Local development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm verify
```

The command checks formatting, tests, the Cloudflare Workers bundle, strict TypeScript, public metadata, security headers, bilingual routes, robots, and sitemap.
