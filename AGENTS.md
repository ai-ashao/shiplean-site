# ShipLean Site Agent Contract

## Product boundary

This repository is the public ShipLean marketing website. It must not contain or distribute the commercial SaaS scaffold source.

## Rules

- Keep all product claims aligned with implemented or explicitly planned capabilities.
- Present the workflow as download template → open coding Agent → invoke bundled Skill → review verified MVP.

- Preserve English/Chinese alternates, canonical URLs, sitemap, keyboard focus, reduced motion, and narrow-screen layout.
- Cloudflare Workers is the only claimed production target.
